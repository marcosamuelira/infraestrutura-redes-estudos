# Módulo 01 - Fundamentos de Infraestrutura de Redes

Estudos realizados com base no curso de Infraestrutura de Redes do professor Robson Vaamonde.

Este módulo aborda os fundamentos das redes de computadores, incluindo infraestrutura, modelos de rede, topologias, meios de transmissão e arquiteturas modernas de comunicação.

## Objetivo

Compreender os conceitos fundamentais das redes de computadores, sua infraestrutura, formas de comunicação e principais arquiteturas utilizadas atualmente.
